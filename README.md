# CSE 341 - Web Services

This repository contains my coursework and assignments for the **CSE 341 - Web Services** course at **Brigham Young University–Idaho**.

## Technologies

- Node.js
- Express.js
- MongoDB Atlas
- pnpm

## Project Structure

```text
cse341/
├── week01/
├── week02/
├── week03/
└── ...
```

## Week 01

A simple REST API built with Express that serves professional profile data from MongoDB Atlas.

### Run the project

```bash
pnpm install
pnpm dev
```

The API will be available at:

```text
http://localhost:8080
```
